# БлокСкан

Неофициальный Android-клиент сервиса **[Cheburcheck](https://cheburcheck.ru)**: проверка доменов, IP-адресов и целых подсетей на блокировки в России
с ожиданием результатов динамических сканеров.

> **БлокСкан не является официальным приложением Cheburcheck и не связан с его авторами.**
> Все данные о блокировках предоставляет сторонний сервис [cheburcheck.ru](https://cheburcheck.ru) через его публичный HTTP API.
> Приложение обращается только к этому хосту. Сам сервис и его код: [LowderPlay/cheburcheck](https://github.com/LowderPlay/cheburcheck).

## Что умеет

- **Проверка IPv4 и IPv6.** Статика (списки блокировок, CDN, ASN, провайдер, страна, жалобы пользователей) и динамика (ответы сканеров из разных регионов и операторов) показываются раздельно.
- **Проверка доменов.** Домен отправляется в API Cheburcheck целиком: приложение показывает все возвращённые A/AAAA адреса, сведения DNS/SNI и результаты сканеров. Динамика запускается по выданному сервисом `id`.
- **Массовая проверка подсетей CIDR.** Cheburcheck не принимает подсеть как одну цель с динамикой, поэтому приложение само разворачивает диапазон и проверяет каждый адрес отдельно.
  Есть калькулятор подсети, режимы «все адреса», «без сети и broadcast», «свой диапазон» и «список IP».
- **Очередь с паузой.** Пауза, продолжение, остановка, повтор неудачных запросов, восстановление после перезапуска приложения, уведомление о ходе работы.
- **Фильтры, поиск, сортировка, экспорт** результатов в CSV, JSON (с исходными ответами сервиса) и TXT. История проверок.
- Светлая и тёмная тема, интерфейс на русском.

## Как приложение использует API Cheburcheck

| Запрос | Для чего |
|---|---|
| `GET /api/v1/check?target=<IP или домен>` | статическая проверка, выдаёт `id` проверки |
| `GET /api/v1/probe/{id}` (SSE) | результаты динамических сканеров: события `started`, `result`, `done` |
| `GET /api/v1/status`, `GET /api/v1/healthcheck` | состояние сервиса и дата обновления баз |

Ключевое правило: **проверка считается завершённой только после события `done`**. Проверка по IP не включает SNI и DNS; для сайта вводите домен. Отсутствие адреса в списках не означает, что он доступен:
сканеры часто присылают блокирующие результаты последними. Подробности и реальные образцы ответов: [docs/API_RESEARCH.md](docs/API_RESEARCH.md).

Нагрузка на чужой сервис ограничена: между запросами есть интервал, запуски сканеров идут не чаще 4 в минуту (максимум 5, настраивается), по умолчанию проверка последовательная.
Лимиты не обходятся. Полная проверка /24 с динамикой занимает больше часа, и это нормально.
Адреса частных сетей (192.168.x.x, 10.x.x.x и т. п.) по умолчанию проверяются только по спискам.

## Установка

Скачайте подписанный APK со страницы [Releases](../../releases) и установите (потребуется разрешить установку из неизвестных источников).
Проверить целостность можно файлом `.sha256` из того же релиза:

```
sha256sum -c BlockScan-vX.Y.Z.apk.sha256
```

Требуется Android 8.0 (API 26) или новее.

## Сборка

Релизы собирает GitHub Actions, вручную собирать ничего не нужно. Для локальной сборки нужны JDK 17, Android SDK (platform 34) и Gradle 8.9:

```
gradle :app:testDebugUnitTest      # тесты
gradle :app:assembleDebug          # APK: app/build/outputs/apk/debug/app-debug.apk
```

## Структура проекта

```
app/src/main/java/ru/blockscan/app/
  core/      IP/CIDR, калькулятор подсетей, планировщик диапазонов, разбор SSE
  domain/    модели, разбор ответов, итоговый вердикт, лимитер, цикл проверки, очередь сканирования
  data/      HTTP-клиент (OkHttp), SQLite, настройки, экспорт
  service/   foreground-сервис с уведомлением
  ui/        экраны Jetpack Compose (Material 3), навигация, ViewModel
app/src/test/  тесты на реальных образцах ответов сервиса
docs/        исследование API и архитектура
tools/       скрипт сбора образцов ответов API
```

Стек: Kotlin, Jetpack Compose, Material 3, Coroutines/Flow, OkHttp, kotlinx.serialization, SQLite.
Архитектура описана в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Ограничения

- Лимит сервиса «5 запусков сканеров в минуту» и кеш результатов на 3 часа известны со слов сторонних клиентов и не подтверждены документацией.
- Результат сканеров отражает состояние сети в момент проверки у конкретных операторов в тех регионах, где есть сканеры; это не гарантия доступности адреса у конкретного пользователя.
- Приложение носит информационный характер.
